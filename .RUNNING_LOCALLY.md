# Cara Running LUMORA Locally 🚀

## Prerequisite
- **Node.js** v20+ (check: `node -v`)
- **pnpm** v9 (check: `pnpm -v`, install: `npm i -g pnpm@9`)
- **Docker** (for PostgreSQL + Redis)

## Step 1: Setup Environment

```bash
# Copy .env.example ke .env
cp .env.example .env

# Edit .env dan generate secrets (copy paste hasil):
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

# Set di .env:
AUTH_JWT_SECRET=<paste_hasil_diatas>
SIGNED_URL_SECRET=<paste_hasil_diatas>
```

Default values sudah oke untuk dev (local storage, console email, etc).

## Step 2: Start Infrastructure

```bash
# Terminal 1: Start Docker services (postgres, redis)
docker compose up -d

# Verify services jalan:
docker ps
# Harusnya ada 2 containers: postgres:16-alpine dan redis:7-alpine
```

## Step 3: Setup Database

```bash
# Generate Prisma client
pnpm db:generate

# Run migration (create tables)
pnpm db:migrate

# Seed dengan demo data (global templates + demo accounts)
pnpm db:seed
```

Demo accounts setelah seed:
- Email: `admin@lumora.dev` → Password: `Lumora123!` (OWNER role)
- Email: `operator@lumora.dev` → Password: `Lumora123!` (OPERATOR role)

## Step 4: Run Development Servers

Option A: Run semua parallel (recommended)
```bash
pnpm dev
# Opens http://localhost:3000 (web)
# + background worker pada port lain
```

Option B: Run terpisah (untuk debugging)

```bash
# Terminal 1: Web app
pnpm dev:web
# http://localhost:3000

# Terminal 2: Background worker
pnpm dev:worker
# Listening untuk BullMQ jobs

# Terminal 3 (optional): Desktop Bridge
pnpm dev:bridge
```

## Step 5: Access Web

Open browser: **http://localhost:3000**

Login pakai demo account:

## Troubleshooting

### ❌ "connect ECONNREFUSED 127.0.0.1:5434"
Database tidak jalan. Jalankan: `docker compose up -d`

### ❌ "connect ECONNREFUSED 127.0.0.1:6379"
Redis tidak jalan. Jalankan: `docker compose up -d`

### ❌ "Module not found"
Dependencies belum diinstall. Jalankan: `pnpm install`

### ❌ "Error: column \"guest_wa_number\" does not exist"
Schema mismatch. Jalankan ulang: `pnpm db:migrate`

### ✅ Verify semua jalan
```bash
# Check database connection
pnpm db:generate

# Check Redis connection
docker exec -it lumora-redis-1 redis-cli ping
# Output: PONG ✓

# Check web app dapat akses DB
curl http://localhost:3000/api/health (kalau endpoint ini ada)
```

## Storage (file upload)

Default dev: **local storage** di `./storage/` folder.

Files:
- Border images
- Photo results
- Thumbnails

Bisa lihat files di folder tersebut setelah session pertama selesai.

## Monitoring Background Jobs

Install **Bull Board** (optional, untuk inspect job queue):

```bash
# Terminal: Run Bull Board UI
npx bull-board --redis localhost:6379
# http://localhost:3001 (Bull Board UI)
```

Dari sana bisa lihat queue status, failed jobs, dll.
